# Critter Flip

Status: raw microgame / second reference implementation
Price hypothesis: $1.99-$2.99 one-time

## One-sentence pitch
Flip cards, match original creatures, and fill your Critter Book in a fast memory game built for kids and families.

## Core hook
A generic memory clone is not enough. Every matched pair unlocks an original creature entry in a persistent Critter Book, giving repeat play a small collection goal.

## V1 modes
- Easy: 6 pairs
- Normal: 10 pairs
- Hard: 18 pairs
- Timed challenge
- Limited-mistake challenge
- Pass-and-play 2 player if implementation remains small

## Progression
- original creature collection
- discovered / undiscovered silhouettes
- best moves/time per difficulty
- no paid loot boxes, ads, accounts, or online dependency

## Accessibility
- large-card mode
- symbols/shapes in addition to color
- keyboard navigation
- visible focus
- reduced motion
- independent music/SFX controls
- optional spoken creature names later if a local implementation is clean

## Commercial/IP rule
All creatures, names, icons, art and audio must be original or commercially licensed. Do not use Pokémon or other third-party entertainment characters/branding.

## Why it belongs in the engine
Critter Flip intentionally stresses different systems from Capture 11:
- tile/grid navigation
- touch input
- simple animation
- timer/move counter
- persistent collection progress
- fast restart/new-board generation

If Capture 11 and Critter Flip can share the same shell/settings/save/accessibility/release plumbing without game-specific hacks, Microgame Engine v0.1 has demonstrated real reuse.
